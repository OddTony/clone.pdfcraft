# Contributor tooling preflight

Use when tool availability, semantic navigation or integration adoption material. Known installed command in verified environment: non-trigger unless configuration changed. Read [task contract](references/contract.md), canonical [tooling decisions](references/tooling.md), and [evidence rules](references/evidence.md). Obtain concrete capability gap, current host/platform, repository/dirty identity, approved effects, existing tool configuration facts, finite inspection budget. Recipe authorizes no installation, dependency fetching, source upload, indexing, daemons or global settings changes.

Distinguish instruction tool name, installed executable, registered plugin skill, exposed MCP method, healthy runtime/daemon, qualified PdfCraft workflow. Inspect versions/help/narrowly needed metadata; no secret/personal configuration dumps. Missing PATH command proves only failure to resolve there. Research-host Windows observations not universal contributor baseline; reread this host's actual capabilities. Absent Rust: finish source/design; record compiler/application checks unrun.

Native fallback: Git/ripgrep, direct current callers/consumers. Stale index: compare reported root/revision/dirty state, returned path/symbol with current disk; reject obsolete edges, trace manually. Do not treat status/search as inert probe if integration may auto-index, resume work, start watchers or pull models. rust-analyzer may execute build scripts/proc macros; review settings before activation. Semantic graph: shortlist, no exhaustive Rust cfg/trait/macro reachability proof.

Example: denied optional MCP request; record missing relationship query, inspect same public/local symbols through ordinary source tools, finish bounded analysis. Never silently install replacement or send private snippets to documentation service. Check public dependency documentation against locked version; retrieved `latest` not compatibility evidence.

Remaining real gap: host-specific proposal with exact package/source/version, integrity/licence status, prerequisites, hooks/executed code, data/egress path, privileges/storage/resources, bounded synthetic smoke, reversible removal, owner, no-tool fallback. Incomplete integrity/rights: conditions, not cleared install. External operation and copying/linking/distributing tool code or instruction assets require separate policy decisions.

Deliver observed capability states, commands/metadata, source freshness checks, refusals/fallbacks, conditional proposals, exact blocked claims. Continue independent authorized work; missing optional tooling means neither product failure nor passing qualification.
