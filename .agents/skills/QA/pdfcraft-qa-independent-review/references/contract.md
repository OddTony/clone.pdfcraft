# Shared task contract

Read current repository AGENTS.md, CLAUDE.md and applicable nested instructions first; they govern recipes. Approved task sets scope. Recipe grants no permission to install software, upload private data, publish, introduce unsafe, change product behavior in tests-only work or weaken gates. Pinned [target policy](https://github.com/storytold/pdfcraft/blob/f0c9901c398372782a4eb001c95638289a5edab0/AGENTS.md) anchors evidence; newer local rules govern.

State requirement, preconditions, action, expected result and forbidden effects. Derive expectations independently. For a meaningful repair, demonstrate intended regression before smallest fix; obtain GREEN with unchanged oracle. Missing import/compiler or rejection before intended guard is another failure. Unavailable RED stays a limitation.

Choose cheapest evidence layer reaching actual boundary. Compiler, pure Rust, real collaborators, egui semantics, native window/AT and browser-WASM prove different things. Keep healthy and plausible wrong controls. Screenshot, same-parser round trip, caught panic or exit zero alone cannot support broader claim.

Review commands, build scripts, features, hooks and external effects before bounded installed-tool execution. Assign writable-resource owners; cap aggregate work, not only each worker. Optional tool refusal: native fallback. Await owned work; observe application cleanup before fixture teardown hides leaks.

Retain source/dirty/config/lock/fixture/artifact identity, exact command/environment, selected versus executed checks, native outcomes, first failures, retries, cancellations, timeouts and cleanup limits. Unknown is not zero or success. Required failed, missing, skipped or blocked evidence keeps qualification incomplete.

Bounded tasks can close with concise evidence prose. Persist plan/result/checkpoint for multi-phase coordination, interruption or explicit record requirement. Select relevant skills; neither contract nor category requires all 41 recipes or orchestration for every task.
